# 项目交接与 Proposal 要点

## 当前方案

| 项目 | 决定 |
|---|---|
| 机械结构 | ORCA Hand v2 的 V1000 右手，使用 N-B 舵机安装件 |
| 舵机 | 新 STS3215，整手 17 个；首批先买 1 个测试 |
| 电控 | FE-URT-2、USB 数据线、匹配舵机电压的外部电源 |
| 打印 | 学校设备；1.75 mm PLA Basic，首卷 1 kg；软模另需约 40–50 g TPU |
| 皮肤 | 自消泡的标称食品级 0 度双组分硅胶，自行浇注 |
| 当前进度 | 3MF 已完成 8 盘切片检查；实物装配和抓取测试待进行 |

## Proposal 写什么

- 项目目标：复现机械手，实现基本动作，并尝试基于电流反馈的抓取控制
- 实现方案：打印结构件、浇注皮肤、安装舵机和腱绳，完成编号、标定与控制
- 计划演示：张手/握合/对捏；用软物体比较固定位置闭合与反馈控制
- 分工：Proposal、采购、打印与硅胶、装配测试，按各人实际承担的任务记录
- 计划预算：按小组讨论暂估 **2,000–2,500 元**；舵机按约 100 元/个计算，17 个约 1,700 元，其余材料按采购报价安排

预算是计划值，不是最终报价。只做本阶段准备时，舵机先购 1 个，其余 16 个在样件测试后补齐。
