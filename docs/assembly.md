# 装配路线

详细操作请从 [ORCA Hand v2 飞特版中文复现教程](tutorial.md) 开始。本页作为阶段速查；教程包含材料购买、学校打印机、皮肤制作、穿绳和单舵机调试。

主教程使用 [官方 v2 视频](https://www.youtube.com/watch?v=TgIz7HiyaoU)，同时查看 [官方补充说明](../hardware/official/orca_v2/base/ASSEMBLY_ADDENDUM.md)。视频展示 DX 电控，手指和手掌等共用机械步骤可参考；供电和通信按选定国产舵机配置。

| 阶段 | 做什么 | 完成时留下什么 |
|---|---|---|
| 打印与清理 | 确认右手、清除支撑、疏通腱绳通道、试装轴承 | 零件照片和实际规格 |
| 单指 | 组装 DP/IP、PP、AP，检查转动与穿线 | 每对腱绳对应的关节标签 |
| 皮肤与手掌 | 按教程在相应节点套皮肤，再完成会封闭通道的装配 | 掌部走线照片 |
| 舵机准备 | 单个设置 ID，核对正反方向和中立位置 | ID 与实体位置表 |
| 舵机仓 | 试装 N-B 适配件、卷线轮、布线和风扇 | 电机安装及线束照片 |
| 接腱绳 | 按关节与舵机映射连接，调整预紧 | 绳路、收线方向、初始位置 |
| 试动与标定 | 单舵机、单指，再到整手 | 自己这只手的范围和零位 |

不要等整只手封装后才考虑掌部皮肤，某些皮肤无法后套。PP 到 AP 的两条腱绳按“靠中心的出口对应靠中心的入口”穿，外侧对应外侧，结合零件朝向判断。

N-B 的关节 ID 候选见 [原配置](../software/orca_core/orca_core/models/v2/orcahand-scs225-right/config.yaml)。其正负号、零位和限位来自作者的实体手，应重新记录本机对应关系。通信线上舵机的连接顺序不能代替 ID；腱绳必须与实际控制的关节对应。

装配期间的异常、修正与照片位置填入 [实物记录模板](../experiments/record-template.md)。
