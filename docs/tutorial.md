## 1. 确认版本与工作顺序

### 1.1 本项目方案

| 内容 | 当前选择 |
|---|---|
| 机械手 | ORCA v2 base 右手，N-B 舵机安装件 |
| 舵机 | 飞特 SCS225 / STS3215，合计 17 个，具体型号待定 |
| 硬质打印件 | 1.75 mm PLA Basic |
| 打印设备 | 学校 P2S 优先，A1、H2D、P1S 也可使用 |
| 皮肤 | 自消泡的标称食品级 0 度硅胶，自行浇注 |
| 控制与供电 | 电脑＋FE-URT-2；匹配舵机电压的外部电源 |

### 1.2 建议推进顺序

选择学校机器 → 切片估料 → 打印小样 → 检查一只舵机 → 试装 N-B 件 → 打印余件和模具 → 制作皮肤 → 装手指与手掌 → 逐个编号 → 装舵机仓 → 接绳与标定 → 整手动作。

皮肤要提前准备好。基础版 PP 皮肤在关闭 PP–AP 关节前套入，掌部皮肤在腕部及塔架封闭前安装，不能把所有皮肤都留到最后。

## 2. 准备材料与工具

### 2.1 自己购买的打印、浇注材料

| 材料 | 购买时怎样描述 | 数量怎么确定 |
|---|---|---|
| PLA Basic 丝材 | 1.75 mm | 首批 1 卷 1 kg，总量按切片克重 |
| 软 TPU 丝材 | 仅用于模具中要求柔性的部分，官方 README 提及约 85A | 先确认学校机器能否打印这种软料；不能时只外包该部分，不必整套外包 |
| 双组分液态硅胶 | 自消泡、低黏度、适合薄壁皮肤；标称 0 度时说明硬度标尺 | 可先买总量 500 g 的 A+B 试制套装；属于本项目起购建议，最终量按模具体积、流道和损耗 |
| 硅胶用色膏 | 与所选硅胶体系兼容，可不加色 | 先做透明/本色小样；黑白外观不是功能必需 |
| 脱模剂 | 仅在所购硅胶与模具材料说明要求时使用 | 少量，先做相容性小样 |
| 瞬间胶 | 凝胶型，固定磁铁等小件 | 1 管参考；不要涂到轴承和绳路 |

配胶比例、工作时间与固化时间按材料随附说明执行。先做一个小皮肤，检查固化、脱模和套装效果，再制作其余皮肤。

### 2.2 同时备好的工具

- 游标卡尺、直尺、电子秤；小批量配胶建议分度值 0.1 g 或更细
- 内六角工具、螺丝刀、镊子、剪线钳、锋利剪刀
- 小锉刀、砂纸、手动通孔工具，用于去毛刺和清孔
- 小刷子、记号笔、标签纸、分格盒
- 一次性混合杯、独立的 A/B 取料工具、搅拌棒和接漏托盘
- 符合硅胶材料说明的手套、护目镜；例如铂金加成型硅胶可能受乳胶污染而不固化，手套材质按产品要求
- 万用表、匹配电压的外部电源、飞特 TTL 转换板和 USB 数据线

倒胶在独立工作区进行，工具不要再用于食物。材料和手工具的具体操作按学校实验室规定及产品说明。

## 3. 使用学校的打印机

### 3.1 学校已有设备

学校提供拓竹 A1、P2S、H2D、P1S，均可用于本项目的 PLA 硬质件。使用 1.75 mm 丝材。

优先用 P2S：当前官方 3MF 已采用 P2S 预设。在 Bambu Studio 选择学校实际安装的喷嘴和打印板；用其他三台时改成对应机型后重新切片。约 85A 的软 TPU 模具单独按软料配置打印。

### 3.2 正确打开官方 3MF

1. 在 Bambu Studio 或能读取该工程的切片软件中打开 3MF，先查看各盘和材质，不立即开始打印
2. 将打印机配置改成学校的实际机器和喷嘴；若学校使用其他切片器，从 3MF 导出所需模型，再按学校配置重新切片
3. 检查零件尺寸和单位为 mm，缩放保持 100%；模型放不下时拆成不同打印批次，不缩小整只手
4. 保留原件的打印朝向，检查支撑是否进入轴承孔、腱绳通道、齿轮槽；移除多余支撑时只改具体位置
5. 查看每一层预览，确认关节卡扣、薄壁和孔槽不是空缺或悬空打印
6. 保存学校设备用的工程到 `local/printing/`；不要覆盖官方子模块中的原始文件
7. 使用这个设备配置生成的打印文件，不能把官方 P2S 机器的成品 G-code 直接交给另一型号机器

### 3.3 官方文件里实际存了哪些参数

以下是本仓库固定版本 3MF 的**全局设置**，不是我替学校机器推荐的整套参数。部分零件还有局部覆盖和修改器，不能只抄这张表重建工程。

| 全局参数 | `Prints-1100.3mf` | `SiliconeMolds-1100.3mf` |
|---|---|---|
| 打印机预设 | Bambu Lab P2S | Bambu Lab P2S |
| 喷嘴 | 0.4 mm | 0.4 mm |
| 丝材直径 | 1.75 mm | 1.75 mm |
| 层高 | 0.16 mm | 0.20 mm |
| 墙层数 | 2 | 2 |
| 稀疏填充 | 15% | 15% |
| 支撑 | 已开启，自动树状支撑 | 已开启，自动树状支撑 |
| 顶 / 底层 | 6 / 4 | 5 / 3 |
| 材料分配 | PLA 与部分 TPU | PLA 与部分 TPU |

喷嘴、热床温度和速度使用所选机器对应的 PLA Basic 预设。

先试打印一根食指的关节件和一个适配位置，检查轴承压入、销钉插入、关节活动和舵机贴合。若孔过紧，先分清毛刺、首层挤压或打印尺寸偏差；不要直接整体放大所有模型，因为这会同时改变轴承中心距和关节配合。

### 3.4 耗材估算

对最终要打印的每一盘记录：材料、模型克重、支撑克重和预计时间。PLA、TPU 分别相加，再按各自切片总量加约 20% 的初次试制余量，这是本项目的预算建议，不是零件标准用量。

例如切片 PLA 总量为 720 g，加 20% 余量后约需 864 g。

## 4. 准备模型并分批打印

### 4.1 获取文件

不熟悉 Git 的成员可以先直接打开下面的文件链接下载 3MF/STL。代码仓库首页的“Download ZIP”不会自动包含子模块内容。

| 用途 | 固定版本入口 |
|---|---|
| 官方完整基础打印工程 | [Prints-1100.3mf](https://github.com/LinkisLethe/orcahand-hardware/blob/0ce26465a4f67c8ab3391cf157853ac24b1fb9c1/orca_v2/base/Prints-1100.3mf) |
| 官方皮肤模具工程 | [SiliconeMolds-1100.3mf](https://github.com/LinkisLethe/orcahand-hardware/blob/0ce26465a4f67c8ab3391cf157853ac24b1fb9c1/orca_v2/base/SiliconeMolds-1100.3mf) |
| N-B 替换件 | [SCS-225/3D-model](https://github.com/LinkisLethe/orca-core-nb/tree/9224bd81343ddab9a076b16fae3e885739994ec5/SCS-225/3D-model) |

需要本地全部工作资料时：

```bash
git clone https://github.com/LinkisLethe/ORCA-Hand-v2-Project.git
cd ORCA-Hand-v2-Project
python scripts/setup_sources.py --hardware
```

这个完整资料脚本会同时获取 N-B 和官方对照代码。只需要打印文件时，直接使用上面的下载链接即可。运行后的本地打印目录是 `hardware/official/orca_v2/base/`；N-B 模型在 `software/orca_core/SCS-225/3D-model/`。

### 4.2 分清哪些打印、哪些替换

- 手指、手掌、共用腕部等继续使用官方右手基础模型，依零件名称和盘内容筛选
- N-B 提供 `scs-225-case.stl`、`base-holder.stl`、`pin-holder.stl`，用来替换对应安装结构，不是在完整官方 FT 舵机架外再叠装一套
- `scs225-case.step` 是编辑源文件；`ST3215 Servo v2.step` 是舵机外形参考，不要把这个电机模型当作需要打印的机械件
- 官方 3MF 中 DX 和 FT 塔架是替代选项，不要两个都打；N-B 改版同样按替换后的组合排盘
- 若计划浇注硅胶皮肤，整手工程内直接打印 TPU 皮肤的盘不是必需品；但模具工程里要求 TPU 的局部模具仍可能需要打印
- 跳过 1100 第 10 盘加工件，不因提供 STL 就用 PLA 打印；N-B 改件与原支架的替换关系按打印清单确认

N-B 舵机架按两片准备，对应 16 个手指舵机。其余一一对应的替换件按原件数量准备；`base-holder` 和 `pin-holder` 的安装位置在打印清单中集中标注。

### 4.3 推荐三批打印

1. **试装批**：一套食指 DP/IP、PP、AP，相关轴承销钉配合件，N-B 替换件样件和一个小皮肤模具
2. **功能批**：试装通过后打印五指、手掌、腕部、舵机安装结构、卷线轮、棘轮及完整模具
3. **收尾批**：外壳、侧板、线盖和损坏/尺寸修正件；外壳可以晚于单指调试

每批打印后按模块装袋，纸条上写零件名、数量、模型版本和材料。检查卡扣没有缺层、轴承座没有裂纹、腱绳孔可疏通、模具接缝完整。

## 5. 制作硅胶皮肤

### 5.1 材料选择与官方配方的区别

本项目使用自消泡的标称食品级 0 度双组分硅胶。按包装说明配胶和固化，首次使用原配方制作小样，不额外加入硅油或稀释剂。

### 5.2 准备模具

1. 选右手、Base 对应模具，把上下模、芯件、夹扣和漏斗摆在一起，先空装一次
2. 清除支撑、碎屑和接缝毛刺，检查浇口、排气通道、薄壁芯件均完整
3. 清洁并充分干燥模具，残水或杂物不能留在模腔里
4. 按模具定位面合拢，用配套夹扣固定；确认合缝闭合、浇口朝上、排气位置开放
5. 将模具放到可接漏的平稳托盘；需要脱模剂时，按相容性小样结果薄涂并按产品要求等待

当前官方模具包含约 85A 软 TPU 掌部模具部件；其余多数为 PLA。硬模与软模承担不同的脱模方式，不把软模简单换成 PLA 后就强行拔出皮肤。学校若不能打印软 TPU，先外包该部分。

### 5.3 先浇一个小样

1. 从最小的手指皮肤开始，确定这一批总胶量；用模腔体积乘材料密度，并加流道/杯壁损耗估算，或先参考模具设计的容积
2. 在杯子上写材料型号和本次 A/B 质量，确认配比按重量还是体积
3. 如果供应商规定重量比 1:1，举例总量 20 g 就是 A 10 g、B 10 g；如果规定 10:1，就按 10:1 重新计算，不能照抄例子
4. A、B 使用独立取料工具，分别称量，避免把带 B 的工具伸回 A 桶
5. 合并后慢速、充分搅拌，刮到杯壁和杯底；若材料说明允许，可换到干净杯里再轻拌，减少杯底未混匀部分
6. 从一处浇口以细流倒入，让液面从低处上升；不要从多个方向同时猛灌，也不要堵住排气通道
7. 按材料说明静置排泡，需要时轻敲模具外侧；不要反复猛烈震动或吹热风来代替固化
8. 标注混合时间，保持模具水平，在说明要求的温度下等待到可脱模时间

### 5.4 脱模与验收

1. 先松夹扣，再逐渐分开外模；从厚边开始轻轻剥离，沿模腔方向释放芯件
2. 不要抓住薄壁皮肤一角猛拉，也不要让刀尖贴着皮肤内部切割
3. 修掉浇口和薄飞边，保留安装边和定位结构
4. 检查表面不发黏、没有未固化液体、薄壁没有贯穿气泡或裂口
5. 套到样件上，检查能否套入、安装边能否就位、屈伸时是否刮住关节
6. 皮肤若太松、太黏或一拉就裂，先区分型号/硬度、配比、固化时间、模具尺寸问题，再决定是否换材料

小样合格后再批量浇注。当前官方 Base 皮肤分为 DP 5 件、PP 5 件、掌部 1 件；同款模具可以复用，不用按官方盘里的批量副本全部打印。各款模具的最少复用组合见 [打印清单](../hardware/3d_print/README.md)。最终仍须与所选骨架修订配套。

完全固化后再用于重复抓握。把配方、环境温度、脱模时间和结果记下来，下次由其他队友也能重做。

## 6. 清理零件和安装 PTFE 衬管

### 6.1 认识零件

| 标记 | 含义 |
|---|---|
| I / M / R / P / T | 食指 / 中指 / 无名指 / 小指 / 拇指；某些共享件不单独写 R |
| DP / IP | 远端 / 中间指节名称；旧视频与当前文件命名可能不同 |
| PP | 靠手掌的一段指节 |
| AP | 侧摆用的指根零件，官方当前文字写 Abduction Phalanx |
| TP | 拇指额外根部零件，官方写 Thumb Phalanx |
| Carpals | 五指连接的手掌基座；R-Carpals 的 R 是右手 |
| Palmar / dorsal | 掌侧 / 手背侧 |
| Spool / ratchet | 卷线轮 / 棘轮调节件 |

### 6.2 清理和试配

1. 去支撑时从外部开始，不把薄卡扣当作钳子的支点
2. 清理 PP 下侧接触面和关节附近粗糙位置，保留原曲面，不磨掉定位肩
3. 轴承先在独立零件上平直压入；不要把整只手装好后再锤轴承
4. 销钉试插，确认没有毛刺阻挡。尺寸有偏差时用卡尺比较孔与销，不直接大幅扩孔
5. 用废腱绳试穿每个通道，拉动时不应被明显刮住

### 6.3 安装导管

腱绳导管可按外径 1.5 mm、内径 0.9 mm 先准备试穿样段，长度按实际通道裁切。

1. 先装各 AP 的两条衬管，再装手掌的 32 个通道和腕/塔架对应的 32 个通道
2. 每段长度由通道实际深度决定，按对应说明保留两侧约 1 mm 露出，不让管口卡进关节运动范围
3. AP 衬管先穿入对应孔道，再按两端露出长度修剪
4. 管子难以推过弯道时，可用一端打结的腱绳穿入管内，再将长端穿过零件，从出口拉动带过 PTFE
5. 管口剪平，清除碎屑，再穿腱绳验证；变形、破裂或明显压扁的管子更换

腕部套在 M4 螺钉上的较粗 PTFE 护套是另一种材料。新网页给出的参考是内径 2.7 mm、外径 4 mm，按螺钉和实际空间剪长；不要与细腱绳导管混淆。

<a id="step-07"></a>
## 7. 准备腱绳和止索结

先使用 BOM 中低伸长的 UHMWPE/PE 编织绳，参考线径 0.39 mm。普通透明尼龙线的伸长和打结表现不同，不作直接替代。

### 7.1 裁绳和标记

预留裁切长度：DP 与 PP 共 10 段、每段 2 m；四指 AP 共 8 段、拇指 AP 2 段、TP 2 段，这 12 段各 75 cm。共 **29 m**，采购时准备至少 50 m 整卷，留出打结和重做用量。

在切每根绳之前写标签，例如 `I-PP-flex`（食指近节屈曲）、`I-PP-ext`（伸展）。同一个关节的两端组成一对，但不是任意两根绳都能接到同一卷线轮。

### 7.2 打结

1. 先用废绳对照 [Ashley 止索结图解](https://www.animatedknots.com/ashley-stopper-knot)练习，收紧后检查结体是否完整
2. DP/PP 双止索结放在绳中间附近，官方新文字参考两个结相距 10 mm、容许约 ±5 mm，以实际结槽能完整容纳为准
3. 官方新教程要求在各 Ashley 结上另加普通单结加强；四指 AP 为一个加强单结，拇指 AP/TP 为三个。依据实际槽位检查能否完整收纳，不把大结强塞进狭窄走线孔
4. 手拉使结体先坐实，再拉回检查；确认不会从锚孔滑脱后，按对应步骤留约 5 mm 尾端并藏进结槽
5. 不使用瞬间胶把所有绳结直接粘死，也不提前剪短还要接舵机的长端

拇指 PP 的绳路若不能让已成形的结通过，先穿绳、在侧面的操作开口打结，再把结收回定位槽，不强行拉结穿过小孔。

<a id="step-08"></a>
## 8. 先装食指，再装其余三指

本阶段不接电机。先把食指完整做通，再复制到中指、无名指和小指，避免同时做错四根。

### 8.1 DP/IP 远端与 PP

1. 找出食指对应的远端件、PP、AP、皮肤、轴承和销钉；把左右朝向与图示摆一致
2. 将远端那根双结绳的两个自由端从结槽向外穿出，拉结坐入定位位，把中间余环藏进槽内
3. 在远端两侧装相应轴承，确认平整、没有顶到绳
4. 在 PP 的结槽中装另一根双结绳，同样将结和连接环藏好
5. 普通四指的参考定位销为 PP 中间一根 Ø2×8、下方一根 Ø2×6；连接远端后还要装上方 Ø2×6，具体位置跟当前模型图
6. 把远端的腱绳穿过 PP 的指定通道，拉直但不拉紧，让轴承对准关节座后卡合
7. 放入上方导向销，使腱绳位于设计的导向位置；轻拉两个远端绳端，确认远端屈伸都顺畅
8. 装 PP 的两侧轴承及对应皮肤，皮肤边缘不要压在关节间隙里

### 8.2 AP 侧摆绳与 PP–AP 连接

1. 确认 AP 两根 PTFE 已就位
2. 将两段 75 cm 绳分别由外向内穿入 AP 的侧摆锚孔，在操作端留足打结长度
3. 打结、加强、拉紧坐实，确认后修短结尾并藏进槽；两根长端保持可识别
4. 把 DP/PP 的四个绳端先穿过 PP 皮肤，套好皮肤，再按图穿过 AP
5. 普通四指的官方新图编号为：1=PP 伸展、2=PP 屈曲、3=远端屈曲、4=远端伸展。这是图中的孔位编号，不能脱离零件朝向直接当成画面左到右
6. 逐根追踪，确认内侧出口对应内侧入口、外侧对应外侧，没有一根绕到另一根背后
7. 卡合 PP–AP，按图安装两根 Ø2×8 导向销及 AP 的两侧轴承

### 8.3 六根绳逐根检查

扶住指根，其他绳保持松弛，每次只轻拉一端，依次观察：远端弯曲、远端伸直、PP 弯曲、PP 伸直、侧摆两个方向。把结果写到绳端标签上。

通过标准是六端动作能区分、关节不卡、轴承不脱座、皮肤不夹进关节。遇到卡顿先查绳路、毛刺和皮肤，不靠加大电机力量处理。

食指通过后，用各自对应的长度和皮肤重复中指、无名指和小指。四指完成后共有 24 个自由绳端。

<a id="step-09"></a>
## 9. 组装拇指

拇指比普通手指多 TP 一段，最终是 8 个绳端。

1. 分别准备拇指 DP、PP、AP、TP 和皮肤，不拿普通手指的件代替
2. DP/PP 按上一节的结槽、轴承和导向方式装配；拇指 PP 如果需要先穿后打结，先完成这个步骤
3. 在关闭 PP–AP 之前套入拇指 PP 皮肤
4. AP 两个锚点各装一段侧摆绳，TP 两个锚点各装一段拇指根部绳；每个结拉紧坐实，尾端完全收进槽
5. 先接 DP–PP，再将其四端按右手图穿过 AP，完成 PP–AP
6. 将 AP 以下的六根通过绳穿过 TP，TP 自己的两根锚绳另外保留；合拢 AP–TP 前确认八端都自由
7. 轻拉每一端，确认四个自由度都能在两个方向活动，再安装到手掌

拇指 AP、TP 的销钉按对应孔槽长度安装，销端完全落入定位槽，腱绳通道保持畅通。

<a id="step-10"></a>
## 10. 组装手掌、皮肤与手腕

### 10.1 将五指接入手掌

1. 确认手掌 32 条导管都已装好、入口出口可见
2. 用右手图定位食指所在安装位；每次只处理一根手指的六根绳
3. 将六端逐一穿过对应手掌通道，轻拉消除松弛，再把指根轴承卡入掌部座
4. 重复其余三指；最后将拇指八端穿入对应通道，安装拇指
5. 汇总应为 4×6＋8＝32 端。逐根轻拉验证，并拍下手掌出口的标签顺序

保持原来的通道顺序，不按自己猜测的“屈曲绳一组、伸展绳一组”重新打乱。

### 10.2 套掌部皮肤和装腕轴

1. 在腕部闭合前把掌部皮肤各定位边就位；不要让皮肤盖住腱绳出口
2. 按当前模型装两根 Ø3×50 腕部销钉、掌侧齿形带轮和两侧轴承
3. 两侧轴承内径与掌轴匹配，轴承平直坐入安装位
4. 将 GT2 闭口带先套在掌侧带轮上，暂不把张力调得很大

### 10.3 穿过腕部

1. 在腕架内放好 M4 方螺母，按对应位置装 M4×20 螺钉、垫圈和粗 PTFE 护套
2. 把手掌和腕架保持分离，朝向与官方右手图一致
3. 从一侧开始逐根穿：官方绳路中掌侧出口组对应腕架背侧入口组，背侧出口组对应腕架掌侧入口组；组内顺序保持不变
4. 每穿一根就从入口追踪回原出口，不一次抓住一把乱穿
5. 32 端全部穿完后再靠拢腕架，确保绳没有被夹进轴承、齿带或壳体接缝
6. 把掌部坐入腕架，带子处在两条带 PTFE 护套的螺钉之间，保留各绳端继续向下连接

“掌背两组在腕部对换”是设计绳路，不等于允许任意两根绳交叉。局部每根线仍应沿自己的通道顺畅通过。

<a id="step-11"></a>
## 11. 单舵机接线、检查和编号

连接关系如下，实际插头针序按转换板和舵机说明核对：

```text
电脑 USB → TTL 串口适配器 → 舵机 DATA
匹配电压的外部电源 → 舵机 VCC / GND
适配器 GND 与舵机电源 GND 相连
```

### 11.1 先检查一只，再批量设置

1. 看舵机完整铭牌和卖家规格，确认 SCS225 或具体 STS3215 后缀、额定电压和 TTL 接口
2. 标准 SCS225 是 7.4 V 级别；STS3215 有不同电压版，供电按所购型号，不凭外形猜电压
3. 断电状态下，将一个舵机接到转换板 TTL 口；按针序接电源正极、地和数据，确认不是 RS485 口
4. 外部电源给舵机供电，电脑 USB 负责通信，地线按转换板说明连接
5. 安装转换板所需驱动，打开飞特调试工具，选择出现的串口和实际波特率
6. 搜索/读取这只舵机，先记型号、当前 ID、当前位置和反馈范围，再做低速小角度试动
7. 检查位置反馈是否随动作变化；能读电流时记录空载动作值，不在空载阶段测最大堵转力

如果无法搜索到，先核对电源、串口、波特率、针序和是否同时被另一个程序占用，不先改一大批 EEPROM 参数。

### 11.2 编号和参考映射

每次只接一只默认 ID 的新舵机，修改 ID 后断电重连并复读，再贴标签。N-B 使用的候选映射如下，可用于本项目初始布置；方向和零位仍要按自己的穿绳确认。

| ID | 关节字段 | 中文位置 | N-B 总线 |
|---:|---|---|---|
| 1 | wrist | 手腕 | B |
| 2 | index_pip | 食指远端屈伸 | A |
| 3 | index_mcp | 食指近节屈伸 | A |
| 4 | index_abd | 食指侧摆 | A |
| 5 | middle_abd | 中指侧摆 | A |
| 6 | ring_abd | 无名指侧摆 | A |
| 7 | ring_mcp | 无名指近节屈伸 | A |
| 8 | ring_pip | 无名指远端屈伸 | A |
| 9 | middle_pip | 中指远端屈伸 | A |
| 10 | middle_mcp | 中指近节屈伸 | B |
| 11 | pinky_pip | 小指远端屈伸 | B |
| 12 | pinky_mcp | 小指近节屈伸 | B |
| 13 | pinky_abd | 小指侧摆 | B |

不要统一强制写入 `2047` 作为所有型号的中点：标准 SCS225 的规格范围与 STS3215 不同，且 N-B 源码中有位置比例冲突。先核对真实范围，再确定各关节初始位置。

<a id="step-12"></a>
## 12. 安装 N-B 舵机仓、卷线轮和线束

### 12.1 机械试装

对照 [N-B 卷线轮实拍](https://github.com/LinkisLethe/orca-core-nb/blob/9224bd81343ddab9a076b16fae3e885739994ec5/SCS-225/Image/spool.png)和模型检查。

1. 用已编号舵机空装适配结构，检查机身贴合、输出轴位置、插头是否能插拔、螺丝孔是否对齐
2. 先试一个输出位：舵盘/适配件能与输出轴正确啮合，中心螺钉长度合适，不能拧到底后仍晃动
3. 按所用卷线轮结构装底轮、棘轮和顶轮，转动时不擦舵机壳，顶轮轴承先在工作台上装好
4. 确认后再复制其他位置，排成与腱绳走向匹配的布局，贴上 ID 和关节标签
5. 腕部电机通过自己的带轮驱动腕关节，和 16 个手指腱绳输出位分开处理

普通舵机包装可能已经附舵盘和螺丝，先清点再补买。不要照 DX 视频把螺钉数量和接口尺寸全部搬过来，也不要拆开舵机机壳角上的螺钉来固定卷线轮。

### 12.2 散热和通信布线

1. 装两只 5010 风扇，整理线束，确保叶片附近没有电线或腱绳
2. 风扇电压按铭牌；若风扇为 12 V、舵机为 7.4 V，分别提供匹配的电源或电压转换
3. 按 N-B 参考布局分成 A 路 8 个和 B 路 9 个，每路单独接 USB-TTL 转换板
4. 两条单链对应 2 根首端线和 15 根舵机间串接线；长度按安装位置选择，先使用规格匹配的随附线
5. 信号插头完全坐实，线束不要压在卷线轮、棘轮或壳体合缝中，两块 USB 板的数据线不要并接到同一条总线
6. 每个电机固定后仍应看得到标签，至少能找到对应插头；先留出检修位置，不急着合壳

此处无需购买或烧录官方 HIVE 控制板，不需要 J-Link，也不使用 U2D2。软件连接方式是电脑经飞特兼容 USB-TTL 适配器通信。

<a id="step-13"></a>
## 13. 接腱绳、调整预紧和标定

### 13.1 先对应关节，再接轮

1. 手保持可观察的中立姿态，电机处在已核对的可用中间位置；装绳和换线时断电
2. 找出同一个关节的两根反向绳，轻拉确认一根负责一个方向，不按绳子“看起来挨在一起”配对
3. 查上一节 ID 表，连接到对应电机的双卷线轮；换电机位置可以，但必须同步改映射
4. 先选食指一个关节做完整样例，确认转动时一根收线、另一根放线，不会同时勒紧

### 13.2 缠绕和固定

官方新文字的参考是：先穿锚固通道、打 Ashley 止索结并坐实，留约 5 mm 尾端藏入，再在轮缘绕三圈，绕时维持轻微张力。三圈规则只在所用轮槽和通道匹配时采用，确保够长再剪；不要照这句话在不同直径的替换轮上硬塞三层交叉绕线。

1. 每圈落在轮槽里，不叠压乱线，不把绳绕到轮背或轴承后面
2. 上轮接同一关节的另一根绳，检查收放方向相反
3. 顶轮轴承和固定件装好后，确认转动顺畅，没有因螺钉过紧被夹死
4. 按小幅度往返检查正确关节运动，再处理下一对；保留余长，完成检查后才修尾

### 13.3 调预紧

棘轮先调到腱绳没有明显松垂、能稳定贴在轮槽内。不要把“拉得越紧越好”作为目标：若关节已经被拉向极限，或两侧同时绷紧，先放松再调。

对每个关节缓慢往返，观察松边是否大量垂落、紧边是否磨孔、转动是否有明显滞后。只调整有问题的一对，避免整手同时改变后无法判断原因。

### 13.4 标定本机行程

1. 用飞特上位机以低速、小增量移动一个电机，观察对应关节实际方向
2. 逐渐接近可用端点，留在顺畅活动范围内；不要靠持续堵转去找极限
3. 记录原始位置下限、上限和中立位置，同时记录关节姿态和照片
4. 再往返一次检查重复性，把方向反转、腱绳松弛或卡顿先处理掉
5. 对其余电机重复；在自己的配置中保存，不覆盖作者示例标定数据

电机编码值不是手指关节角度。腱绳伸长、绕线半径和预紧会影响映射，所以换绳、换卷线轮或明显调张力后，要重新检查受影响的关节。

<a id="step-14"></a>
## 14. 安装磁铁、外壳并完成试动

1. 先把壳体与塔架配对摆放，用未粘的磁铁确认相对面互相吸引，标记方向
2. 每槽少量胶，放入磁铁并保持位置，按胶水说明等待固定；擦去外溢胶
3. 合壳检查磁吸是否到位，开壳时磁铁不应被另一侧吸出安装槽
4. 线束收进预留槽，保持风扇、卷线轮、棘轮和腕部带轮活动空间
5. 装好桌面支撑，防止运动时整机倾倒；不接机械臂时不用照买全部 Franka 安装件
6. 先逐指小幅开合，再做整手轻握、张手、拇指对掌、手腕小幅运动

完成检查：所有关节顺畅、皮肤不夹入、轴承不松脱、绳结不滑动、轮槽不跑线、线束不拉扯、磁铁与外壳固定可靠。存在某个关节问题时单独处理，不用提高整手力度掩盖。

<a id="step-15"></a>
## 15. 接入控制程序和做抓取演示

### 15.1 “把接口接入主程序”包含什么

N-B 当前公开主分支里有 `scs225_client.py`，但主程序的支持列表和驱动工厂还未登记 `scs225`。所以补入口是第一步，之后还要把 SDK 依赖、两路本机串口、位置换算和本机标定配置配齐。

这份教程没有修复该代码缺口，也不提供声称已经跑通的整手启动命令。机械装配和飞特上位机检查可以先进行，软件接入按 [软件说明](software.md)继续。

软件阶段的顺序是：

1. 在本机安装对应 SDK，只接一只空载舵机，先读取型号、位置与反馈
2. 接入正确型号驱动；SCS225 和 STS3215 不因机身尺寸相同而共用同一套寄存器处理
3. 核对位置范围；标准 SCS225 规格写 0–1023 对应 300°，N-B 当前代码却按 4096 格/360°，必须依据实物确认或修正
4. 配置两个实际串口，替换作者固定的 `/dev/serial/by-id/...`，检查两组 ID 都能被唯一找到
5. 用本机标定记录配置关节到电机映射，再测试单指、整手和姿态回放

### 15.2 电流阈值抓取

先用海绵等物体，以较低速度闭合，读取各关节空载与接触后的电流变化。接触后要让目标不再继续深入，并保留合适抓持力；不是停止发包后仍让舵机追赶过深的旧目标，也不是直接全部断电。

N-B 的 `set_max_current(500)` 在 SCS225 适配中代表原生扭矩限制值，不是 500 mA。电流反馈的单位与比例另行核对，不能直接当作指尖夹持力。

最初演示可按张手 → 人托住物体 → 缓慢闭合 → 夹稳后人松手 → 人接回 → 按钮释放的流程。垂直固定的手张开时不会自动托住物体，不增加尚未具备的“自动递送”承诺。

<a id="step-16"></a>
## 16. 排查常见问题

| 现象 | 先检查什么 | 下一步 |
|---|---|---|
| 轴承压不进去 | 支撑、首层挤压、孔径、轴承规格 | 清理和量尺寸；用小件验证打印补偿 |
| 手指空手就卡 | 绳交叉、导向销、粗糙表面、皮肤边 | 松开对应关节，逐项处理后再接电机 |
| 同样指令动作忽大忽小 | 腱绳松弛、结未坐实、轮槽叠线 | 重新坐结和调整预紧，复查标定 |
| 硅胶到时仍黏 | 配比、混匀、温度、材料污染 | 对照同批小样判断；更换污染工具，重做小批 |
| 皮肤易裂 | 过早脱模、硬度/撕裂性能、薄壁气泡、尖角 | 先完成固化和小样试装，再决定材料或模具修正 |
| 舵机搜不到 | 电源、TTL 针序、串口、波特率、占用 | 退回单舵机链路排查 |
| 指令让错误手指动 | ID 与腱绳配对 | 重查标签与映射，不先改角度比例 |
| 一通电就很用力 | 初始目标、过紧预拉、错误中点/方向 | 停止动作，放松相关绳，核对范围再试 |
| 风扇不正常或很慢 | 风扇铭牌、电压、叶片是否被线挡住 | 提供匹配供电并整理线束 |

每处理一个问题，记录改了哪个零件、哪一对绳或哪个参数；复查这部分后继续，不重新无差别调整全部关节。
