# 通信与供电

```text
电脑 USB → TTL 串口适配器 → 舵机 DATA
匹配舵机额定电压的外部电源 → 舵机 VCC / GND
适配器 GND 与舵机电源 GND 相连
```

这是连接关系，不是插头针脚顺序图。实际三针接口按舵机和转换板说明对应，不能用插头能插入或线色判断。

| 路线 | 当前信息 |
|---|---|
| 官方 FT | BOM 使用 FE-URT-2 USB-C，HL-2915/HL-3930 和 12 V 电源 |
| N-B SCS225 | 两个 USB 串口适配器，1 Mbps；标准 SCS225 使用 7.4 V 级别电源 |
| STS3215 候选 | 转换板、单/双总线及电压版尚未确定 |

N-B 默认分组为 BUS-A：2–9；BUS-B：1、10–17。它的 `dual_scs225_client.py` 默认串口是作者 Linux 机器的 `/dev/serial/by-id/...`，不能直接用在本机。

电源按所购型号额定电压选择，整手所需电流容量要结合同时动作负载。SCS225 的舵机电源与官方可能使用的 12 V 风扇需要分别处理；本项目没有指定未经确认的统一电源接法。

首次设置编号时每次只连接一个新舵机。完成编号后再按分组串接；两路通信若共用电源，其地线关系仍需正确。不要把两块 USB 适配器的数据线并到同一总线上。
