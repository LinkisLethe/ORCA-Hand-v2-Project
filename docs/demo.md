# 课程演示计划

本页是目标，不是已完成结果。

核心演示围绕一套控制流程：张手、闭合、接触判断、保持、释放。先做张手/握合/对捏，再加电流阈值抓取。

| 演示 | 物体 | 记录 |
|---|---|---|
| 固定位置与反馈闭合对比 | 海绵块 | 变形程度、电流、是否保持 |
| 不同尺寸的抓持 | 轻质圆柱、方盒 | 成功次数、保持时间、闭合时间 |
| 固定位置交接 | 轻质盒子 | 人托住物体，夹稳后松手；接回后再释放 |

垂直安装时，人或托架要在机械手夹稳前支撑物体，张手释放前也先接住。不要把固定底座的接握演示描述成机械臂主动递送。

电流曲线可展示控制过程；没有力标定时不标成指尖夹持力。摄像头手势跟随作为扩展，强化学习与掌内转笔不列入当前必做范围。
