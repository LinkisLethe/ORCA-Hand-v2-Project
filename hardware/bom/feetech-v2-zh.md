## 材料规格中英对照

| 原文 | 中文解释 |
|---|---|
| M2 / M3 / M4 | 公制螺纹公称直径分别为 2 / 3 / 4 mm；不是螺丝头或扳手尺寸 |
| M3×8；DIN 912 | M3 螺纹、杆长 8 mm；DIN 912 通常为圆柱头内六角螺钉，杆长不含头 |
| Bearing 4×8×3 | 轴承：内径 4 mm × 外径 8 mm × 厚度 3 mm |
| Dowel pin 2×8 | 圆柱定位销：直径 2 mm × 长度 8 mm；通常为光轴，不是螺纹件 |
| Washer / Quad nut / Hex nut | 平垫圈 / 方螺母 / 六角螺母 |
| Threaded rod | 全牙螺杆；例如 M5×100 表示 M5 螺纹、长 100 mm |
| GT2 belt | GT2 同步带；此表为闭口带，142 mm 为周长、6 mm 为带宽 |
| UHMWPE tendon | 超高分子量聚乙烯腱绳，也常称 PE 编织线；不等同于普通尼龙线 |
| PTFE tube | 聚四氟乙烯管／特氟龙管；采购必须区分内径、外径和长度 |
| 3XP / 3-pin cable | 三针三芯连接线；TTL 舵机通常为 VCC、GND、DATA，针序按实际接口 |
| TTL / RS485 | 两种不同电气接口；本项目选择 TTL，转换板上的 RS485 口不能直接替用 |
| 5010 fan | 50 mm × 50 mm × 10 mm 风扇；尺寸不包含电压信息 |
| Qty / Spares | 安装基准用量 / 备件；本表不把备件重复计入安装量，空白表示未指定 |
| Plastic / metal gear | 塑料外壳 / 金属齿轮；塑料壳不意味着塑料齿轮 |
