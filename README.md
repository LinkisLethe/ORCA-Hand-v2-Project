# ORCA Hand 课程项目

方案：**V1000 右手＋N-B 安装件＋飞特 STS3215 新舵机**。整手需 17 个舵机，首批先买 1 个测试。当前已整理好前期交接文件，下一步是采购、打印和实物验证。

## 按分工打开文件

| 负责什么 | 打开哪个文件 | 现在做什么 |
|---|---|---|
| Proposal | [项目目标、预算和提交要求](docs/project.md) | 完成并核对两页内的 proposal |
| 采购 | [Excel 材料清单](hardware/bom/ORCA_v2_Feetech_BOM_中文.xlsx) | 舵机先买 1 个，核对其余配件和耗材 |
| 打印与硅胶 | [3MF 工程](hardware/3d_print/ORCA_v1000_NB_Right_P1S.3mf) · [打印说明](hardware/3d_print/README.md) | 准备 1 kg PLA、约 40–50 g 软 TPU 和硅胶材料 |
| 装配与测试 | [中文教程](docs/tutorial.md) | 先完成单舵机测试和一根手指，再扩展整手 |

**打印盘＝同一批摆在打印机平台上的零件。** 工程共 8 盘，通常分 8 批打印，使用同一块实体打印板即可。文件采用 P1S / 0.4 mm 预设；学校若用 P2S、A1 或 H2D，先切换对应机型再切片。
